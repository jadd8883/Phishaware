# PhishAware – Phishing Awareness Simulation Tool

## 📌 About the Project
PhishAware is a web-based cybersecurity awareness tool developed using Python, Flask, and SQLite. It helps users learn to identify phishing emails through simulated scenarios, interactive quizzes, automated scoring, and instant feedback.

## ✨ Features
- **Phishing Simulation:** Practice identifying suspicious and legitimate email examples.
- **Interactive Quiz:** Test phishing awareness through multiple-choice questions.
- **Automated Scoring:** Calculate quiz scores and display results instantly.
- **Instant Feedback:** Explain the warning signs in each scenario.
- **Result Tracking:** Store quiz scores and timestamps using SQLite.
- **Responsive UI:** Access the application through a user-friendly web interface.

## 🛠️ Technologies Used
- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## ⚙️ Installation and Setup

### 1. Clone the repository
```bash
git clone https://github.com/jadd8883/Phishaware.git
cd Phishaware
```

### 2. Create a virtual environment
```bash
python -m venv .venv
```

### 3. Activate the environment

**Windows PowerShell**
```powershell
.venv\Scripts\Activate.ps1
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Run the application
```bash
python app.py
```

### 6. Open in your browser
Visit: http://127.0.0.1:5000
